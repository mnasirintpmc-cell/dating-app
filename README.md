# 💘 SymmetryMatch

SymmetryMatch is an experimental dating app prototype built with **Streamlit** that estimates facial symmetry from a user-uploaded photo and matches users with others who have similar symmetry scores.

This project is intended for educational and exploratory purposes only.

---

## 🧠 What the App Does

- Accepts a clear, front-facing facial photo
- Detects facial landmarks using MediaPipe Face Mesh
- Calculates a facial symmetry score
- Normalizes the score to a 0–100 scale
- Displays potential matches with similar symmetry levels

---

## 🛠 Technology Used

- Python
- Streamlit
- MediaPipe Face Mesh
- NumPy
- Pillow
